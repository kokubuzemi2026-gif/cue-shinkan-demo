- 最終更新: 2026-08-27（ドラフト作成日）

## 1. 収集する情報

### 新入生

| 情報 | 例 | 団体への見え方 |
|---|---|---|
| 大学メールアドレス | `...@stu.kobe-u.ac.jp` | **見えない**（認証にのみ使用） |
| 興味カテゴリ | アウトドア、音楽 | 集計（人数）のみ |
| 活動目的 | 友達、挑戦、運動、創作 | 集計のみ |
| 活動スタイル | ゆるく／ほどほど／本格的 | 集計のみ |
| 希望頻度 | 月1／週1／週2以上 | 集計のみ |
| 参加可能曜日 | 平日夜、土日 | 集計のみ |
| 1回あたり予算 | 1回2,000円以内 | 集計のみ |
| 経験 | 未経験／少し／経験者 | 集計のみ |
| 受信設定 | カテゴリ・上限・停止 | **見えない** |
| オファーの既読・返答 | 行ってみたい 等 | 集計（匿名件数）のみ |

### 団体担当者

- 大学メールアドレス（認証にのみ使用。学生には見えません）
- 団体名・説明・公式窓口（団体が入力するもの）
- 団体内での表示ラベル（氏名・メールを含まないランダムな表示名）

## 2. 収集しない情報

本サービスは、次を**収集しません**。

- 氏名、顔写真、学籍番号
- 性別、国籍・人種・宗教、病歴・障害
- 電話番号、正確な住所・位置情報
- 自由記述の自己PR

## 3. 利用目的

- 収集した興味・条件は、**条件の合う団体のオファーを届けるため**にのみ使います。
- 大学メールアドレスは、本人確認（ログイン）と、オファー到着のメール通知にのみ
  使います。メール本文には、あなたの希望条件・団体名・イベント名・返答状態を
  **載せません**（届いた事実と受信箱へのリンクだけを送ります）。

## 4. 団体に見える情報・見えない情報

- 団体に見えるのは、**受信を許可した条件に合う新入生の人数（区分・匿名集計）**
  だけです。
- 対象人数は正確な人数ではなく区分（`0` / `1〜4` / `5〜9` / `10〜24` / `25〜49` /
  `50以上`）で表示され、5人未満へは配信できません。
- 配信後のファネル（閲覧・関心・参加意向）は、10人未満のときは開示せず、
  各項目も10人未満なら伏せ、開示する数値は5人単位に丸めます。
- **氏名・メール・学籍番号・個人の一覧は、団体からは一切見えません。**
- あなたが「行ってみたい」を選んだ後にだけ、団体の公式窓口（団体が登録した連絡先）が
  あなたに表示されます。あなたの連絡先が団体に渡ることはありません。

## 5. 保存期間

- 興味パスポート・受信設定・同意の記録は、あなたが削除するまで保存します。
- オファーの配信・受信・既読・返答は、履歴として保存します（あなたのアカウント
  削除で消えます）。
- メール送信のための一時的な記録（送信待ち・送信結果）は、宛先や本文を保存せず、
  送信の状態だけを保持します。

運営の操作記録は**365日**で削除します（`docs/runbook_operations.md` §8）。
この記録に、あなたの氏名・メールアドレス・希望条件は含まれません。

【要確認】無操作アカウント・卒業後アカウントの保存期間の上限は未定です。
通知メールの送信記録（宛先・本文を持たない管理用の行）の保持期間も未定です。

## 6. 削除の方法

- **興味パスポートの削除**: 新入生ホームの「アカウント」から削除できます。以後の
  配信対象になりませんが、すでに届いた案内と返答は受信箱に残ります。
- **アカウントの削除**: 「アカウント」から削除できます。CUEに保存したあなたの
  データ（パスポート・通知設定・受信箱・返答・同意記録）が削除されます。
- **大学メールでのログイン情報の削除**: 認証アカウント（大学メール）は、上記の
  削除では消えず、運営が別途削除します。それまでの間、あらためて新入生として
  登録し直すこともできます。
- **団体からの脱退**: 団体ホームから脱退できます。ただし、あなたが唯一の代表者の
  団体は、代表者不在を防ぐため脱退できません。

## 7. 削除の記録

- 削除が行われたことは、**個人を特定できない日次の集計**（何を・いつ・何件）
  としてのみ記録します。誰が削除したかは記録しません。

## 8. 安全のための管理

- 認証情報・送信のための鍵は、公開範囲を限定して管理し、団体・第三者へ渡しません。
- 団体向けのデータは、設計上、個人を特定できる情報を含みません。

## 9. 第三者提供

- 本サービスは、あなたの情報を広告目的で第三者へ提供・販売しません。
- メール送信のために、メール配信の仕組み（SMTP等）を利用します。

【要確認】利用する外部サービス（メール配信基盤・ホスティング）の具体名と、
それらの所在地・データ取扱いの明示。委託先一覧。
