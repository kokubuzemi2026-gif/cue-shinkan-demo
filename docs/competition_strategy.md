# Competition Strategy

## 1. 勝ち筋

勝つための主張は「サークル検索を便利にした」では弱い。

> 探せる人だけが参加できる新歓から、まだ動けていない人にも安全なきっかけが届く新歓へ。

この構造転換を、学生側・団体側の両画面が連動するデモで証明する。

## 2. 競合との差

| サービス | 主な体験 | 新入生の最初の行動 | CUEとの差 |
|---|---|---|---|
| Penmark | 学内コミュニティ・掲示・交流 | 情報を見る、探す | 団体からの許可制オファーが中核ではない |
| CIRCLES | サークル検索・入会申請・イベント参加・団体管理 | 検索・申請 | 学生側から始まる応募導線が中心 |
| クルサ！ | 大学・ジャンル・本気度等で検索、運営確認済み団体 | 絞り込み・連絡 | 検索体験の改善が中心 |
| CUE | 興味パスポート、条件マッチ、理由付きオファー | 受信条件を登録 | 団体発・匿名・許可制・低圧な返答 |

「国内初」などの断定は、追加調査なしに使用しない。

## 3. 模倣されにくい企画の核

単なるDM機能ではなく、次を一体化する。

- 学生の興味パスポート
- 団体には個人一覧を見せない集計型ターゲティング
- オファー上限
- マッチ理由と不一致条件
- 保留を含む3段階返答
- 送信から参加意向までのファネル

この構造により、逆オファーへの典型的な反論をプロダクト自体で回答できる。

## 4. 90秒デモ案

### 0〜15秒: 問題

「今の新歓は、興味を持った新入生が自分で団体を探し、自分から連絡しなければ何も始まりません。動ける人だけに機会が偏ります。」

### 15〜35秒: 新入生の準備

アウトドア、初心者、土日、月2回程度などをタップして興味パスポートを完成させる。

### 35〜55秒: 団体側の操作

アウトドア団体が初心者向け体験会を作り、対象条件を設定する。「12人とマッチ」と表示され、送信する。

### 55〜75秒: Wow moment

学生画面へ切り替えるとオファーが届く。「アウトドアに興味」「土日参加可」「初心者歓迎」の3理由を見せる。

### 75〜90秒: 安心設計と成果

学生が「行ってみたい」を選び、団体側のファネルが更新される。最後に「団体には学生の個人一覧を見せず、件数も制限しています」と示す。

## 5. 審査で見せるべき画面

優先順は次の通り。

1. 団体がオファーを作る画面
2. 学生にオファーが届く瞬間
3. マッチ理由付きオファー詳細
4. 学生の3段階返答
5. 団体側ファネルの更新
6. 興味パスポート

設定画面やプロフィール編集を作り込みすぎない。

## 6. 評価軸別の対策

| 想定評価軸 | 勝つための証拠 |
|---|---|
| 新規性 | 従来の検索・応募と、逆オファーの構造比較 |
| 課題理解 | 新入生と団体双方の摩擦を説明 |
| UX | 一連の操作がスマホ上で迷わず完了 |
| 技術 | 条件マッチと両ロールの状態連動 |
| 信頼性 | 匿名、許可制、上限、理由表示 |
| 実現可能性 | 小さなMVPと段階的拡張 |
| 検証 | 新入生・団体担当者への短時間インタビュー |

## 7. ユーザー本人の優位性

ユーザーはアウトドアサークルの設立経験があり、団体側が新規参加者へ接点を作る難しさを当事者として検証できる。これはプレゼンで強いが、経験を一般化しすぎない。

発表までに次を記録する。

- 設立時、どの経路で参加者を集めたか
- 興味はあったが参加しなかった人の反応
- 新歓担当が時間を使った作業
- 参加前に頻出した質問
- 参加に至った決め手

## 8. 最小の検証

### 新入生または入学直後を思い出せる学生: 5人

- 自分からDMする心理的負担
- 受け取ってよいカテゴリ
- 迷惑と感じる件数
- 団体に見られてもよい情報
- 「オファー／招待／案内」のどの語が最も自然か

### 団体の新歓担当: 3団体

- 現在の集客経路
- 接点を持てない層
- どの条件なら案内を送りたいか
- 学生個人を見られない集計配信でも使いたいか
- 送信後に知りたい指標

## 9. やらないこと

- 機能数で競う
- AIという言葉だけを付ける
- 実在学生データを集める
- 完成していないチャットや認証に時間を使う
- 「オファー数」を成果として誇る
- 安全性への反論を発表で初めて考える

## 10. 30秒ピッチ

従来の新歓は、新入生がサークルを探し、自分から連絡しなければ始まりません。興味があっても、最初の一歩が重くて動けない人がいます。CUEでは、新入生が興味や参加できる曜日を登録すると、相性の合う団体から、なぜ自分に届いたかが分かる新歓案内を受け取れます。団体には学生の個人一覧を見せず、通知数も学生自身が制御できます。新歓を「探して応募するもの」から、「安心できるきっかけが届くもの」へ変えます。
