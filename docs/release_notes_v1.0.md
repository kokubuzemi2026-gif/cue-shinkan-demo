# CUE（仮）v1.0.0 リリースノート（閉鎖β）

**これは閉鎖β版です。** 神戸大学の学生メール（`@stu.kobe-u.ac.jp`）を持つ利用者だけが使えます。

公開URL: https://kokubuzemi2026-gif.github.io/cue-shinkan-demo/

## このバージョンでできること

### 新入生

- 大学メールの6桁コードでログインする（パスワード不要）
- 興味パスポート（興味・活動目的・スタイル・頻度・曜日・予算・経験）を登録する
- 条件の合う団体からオファーを受け取る。**応募・自己紹介文・DMは不要**
- 「行ってみたい」「あとで考える」「今回は見送る」の3つで返答する。いつでも変えられる
- 「行ってみたい」を選んだあとだけ、団体の公式窓口が見える
- 受信カテゴリ・週あたりの上限・受信停止をいつでも変更する
- メール通知を「オファーごと」「1日1回のまとめ」「通知しない」から選ぶ
- 興味パスポートとアカウントを自分で削除する

### 団体

- 団体を作る（運営の確認が終わるまで配信できない）
- 招待リンクで担当者を増やす（一度だけ使える・7日で期限切れ）
- 公式窓口を登録する
- オファーを作り、**対象人数を区分で確認してから**送信する
- 配信・閲覧・関心・参加意向の匿名ファネルを見る

### 運営

- 団体の確認（verified）・停止（suspended）
- 個別オファーの停止、全体の緊急停止（kill switch）
- 運営操作の監査記録の確認
- 健全性の確認（`platform_health()`）

## 守っていること

| 約束 | 実装 |
|---|---|
| 団体に見えるのは人数の区分だけ | `preview_offer_audience` が区分のみ返す（D036） |
| 5人未満へは配信できない | `send_offer` が `insufficient_audience`（D036） |
| ファネルは10人未満非開示・5人単位丸め | `list_org_campaigns`（D037・英国ONSの10–5ルールを参考。**法令準拠は主張しない**） |
| 氏名・顔写真・性別・国籍・学籍番号で学生を検索できない | そもそも保存していない |
| 「行ってみたい」の前に連絡先が渡らない | `list_my_inbox`（D033） |
| メールに希望条件・団体名・返答を載せない | `email_outbox` が本文・宛先の列を持たない（D041） |
| 同意しないと登録・団体運営ができない | 8つのRPCが `consent_required`（D050） |
| 断る・止める・消す操作は同意を条件にしない | 上記の対象外（D050） |
| 週間受信上限を団体をまたいで守る | 学生1人1行の枠を `FOR UPDATE` で確保（D037） |

## 既知の制限

**公開前に必ず `docs/launch_plan.md` §7.1 の既知リスク一覧（27件）を読んでください。**
**P0は0件、P1は5件**で、P1は公開判断で明示的に受容が要ります。
特に重要なもの:

- **利用規約とプライバシーポリシーはドラフト**。法令適合は未確認で、
  事業者情報・連絡先・準拠法は未確定（`【要確認】`で明示）
- **退会してもログイン情報（大学メール）は残る**。運営が別途削除する
- **入力欄の枠のコントラストが WCAG 1.4.11 を満たしていない**
- **スクリーンリーダー実機での確認が未実施**
- 団体そのものの削除、担当者の削除・role変更は未実装
- まとめメールは取り消せない
- 緊急停止は配信済みの案内を止めない（個別停止を使う）
- 外部の監視サービスを使っていない。運営が毎日 `platform_health()` を見る運用
- 監査ログ・preview・送信し終えたメール行の剪定は**手作業**（自動実行しない）
- **Auth の Attack Protection（CAPTCHA・レート制限）が未設定**（§7.1 B7・P1）。
  公開前にDashboardで設定してください
- **hosted staging での通し確認が未実施**（`docs/launch_plan.md` §7 H1・H9）。
  migration適用・backup・restore・secret rotation・公開停止の各手順は
  文書としては用意しているが、実行しての確認はできていない

## rollback

**履歴を破壊するrollbackは行わない。**

1. まず緊急停止（`docs/operations.md` §5）。配信が止まる
2. コードを戻すなら revert PR を `main` へmerge。Pagesが再deployする
3. 公開そのものを下ろすなら Settings → Pages → Source を「None」へ
4. migrationは逆migrationを新しく書く（`docs/runbook_operations.md` §4）
