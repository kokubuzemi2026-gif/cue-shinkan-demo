# Claude Code 個別タスク用プロンプト

以下を毎回埋め、1回のプロンプトで1タスクだけ依頼する。

```text
あなたはこのリポジトリの実装担当です。

## タスク
[タスク名]

## 目的
[この変更が誰の何を改善するか]

## 最初に読むファイル
- CLAUDE.md
- docs/decisions.md
- [今回必要な仕様書]
- [対象タスクファイル]

## 変更してよいファイル
- [path]

## 変更してはいけない範囲
- [out of scope]

## 実装要件
1. [要件]
2. [要件]
3. [要件]

## 受入条件
- [画面または動作として確認できる条件]
- [エラー・空状態]
- [スマートフォン表示]
- [テスト条件]

## 作業手順
1. まず関連ファイルを読み、変更予定ファイルと実装方針を提示する。
2. 仕様に矛盾または不足があれば、編集せず質問する。
3. 問題がなければ実装する。
4. formatter、lint、typecheck、test、buildのうち利用可能なものを実行する。
5. 変更概要、変更ファイル、検証結果、残るリスクを日本語で報告する。

無関係な修正、依存関係の追加、仕様にない機能追加は行わないでください。
```
