# Task 016: UX・アクセシビリティ・完全E2E

## Goal（目的）

スマートフォン幅で、新入生と団体担当者の主要導線が最後まで破綻なく通ることを保証する。
キーボード操作・フォーカス・ラベル・コントラスト・エラー表示など、基本的なアクセシビリティを満たす。

## Source of truth（正本）

- `AGENTS.md`: §5（UI/UX）
- `CLAUDE.md`: UI要件
- `docs/launch_plan.md`: §2.4
- 各機能タスクの受入条件

## In scope

- `app/src/**`（UI・スタイルの修正。ロジックの仕様変更はしない）
- `app/e2e/**`
- `docs/launch_plan.md`、`tasks/016-ux-accessibility-e2e.md`

## Out of scope

- 新機能の追加、仕様変更
- デザインの全面刷新

## Acceptance criteria

- [ ] スマホ幅390pxで全主要導線が横スクロールなしで通る
- [ ] 主要画面に loading / empty / error / retry の状態がある
- [ ] キーボードだけで主要導線を完了できる
- [ ] フォーカスリングが見える。画面遷移でフォーカスが適切な位置へ移る
- [ ] すべての入力にラベルがある
- [ ] 色だけに意味を依存させていない
- [ ] コントラスト比が基準を満たす（測定結果を記録する）
- [ ] バリデーションメッセージが具体的で、どこを直せばよいか分かる
- [ ] 二重送信が防止されている
- [ ] ブラウザバック・再読み込み・セッション切れで壊れない
- [ ] 新入生の完全なE2E（登録→パスポート→受信→返答→窓口開示→設定変更→削除）がある
- [ ] 団体の完全なE2E（登録→団体作成→確認待ち→verified→窓口→オファー→送信→ファネル）がある
- [ ] lint / test / build / E2E がgreen
